# Urban Mobility & Economic Productivity Analysis

## Project Overview
This project analyzes the relationship between urban mobility and economic productivity using real-world datasets from the TomTom Traffic Index and OECD Cities database.

The objective was to identify cities with:
- High congestion and low economic productivity
- Efficient mobility and strong economic indicators
- Urban patterns that could support infrastructure investment decisions

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Sources
- TomTom Traffic Index
- OECD City Economy Dataset

## Project Workflow
1. Data cleaning and preprocessing
2. Standardization of city and country names
3. Filtering and aggregation for 2024 data
4. Dataset merging and validation
5. Exploratory Data Analysis (EDA)
6. Visualization of traffic and economic indicators
7. Interpretation of urban mobility patterns

## Key Analyses
- Congestion vs GDP per capita
- Traffic delays vs unemployment rates
- Identification of high-efficiency urban models
- Detection of high congestion / low productivity cities

## Key Insights
- Some cities showed strong economic performance despite high congestion levels.
- Cities with efficient mobility systems tended to present stronger economic indicators.
- Traffic congestion appeared to correlate with lower urban productivity in several regions.

The analysis provides data-driven insights that could support:
